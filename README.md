# SIMU

**Sistema Interno de Monitoreo de la Unidad**

Prototipo académico diseñado para apoyar la conducción de una unidad nivel regimiento. La arquitectura contempla los cinco campos de la conducción y desarrolla, en esta etapa, el módulo **P-1 Personal**.

## Alcance del prototipo

- Resumen del mando.
- Organización de la Plana Mayor.
- Módulo P-1 Personal.
- Portal de consulta para el personal.
- Control demostrativo de vacaciones, permisos y disponibilidad.
- Espacios previstos para P-2 Inteligencia, P-3 Operaciones, P-4 Logística y P-5 Asuntos Civiles.

## Uso local

1. Descargue los archivos del repositorio.
2. Abra `index.html` en un navegador web actualizado.

El prototipo funciona con datos demostrativos y no contiene información institucional real.

## Archivos principales

- `index.html`: estructura de la aplicación.
- `styles.css`: presentación visual.
- `app.js`: navegación e interacción.

## Advertencia

Este producto es un prototipo académico. Su empleo con datos reales requerirá controles de acceso, protección de datos, respaldo, auditoría y autorización institucional.
